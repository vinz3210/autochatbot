AutoChatbot

Auto-respond to Twitch chat commands

📡 Monitor multiple channels at once
⚡ Set custom trigger phrases & responses
🔢 Optional auto-incrementing counters
🔒 Restrict triggers to specific users
🧮 Variables & live data from JSON APIs

AutoChatbot monitors Twitch chat channels in real-time and automatically sends responses when specific trigger phrases are detected.

Getting Started

  • Log in with your Twitch account to authorize chat reading & sending
  • Add channels you want to monitor (e.g., your own channel)
  • Create triggers with a phrase and a response
  • Keep the page open — it runs as long as the tab is active

Trigger Phrases

Set any text as a trigger (e.g., !sun). When someone types that exact phrase in chat, AutoChatbot sends your configured response. Matching is case-insensitive.

Allowed Users

By default, anyone can activate a trigger. To restrict it, enter comma-separated usernames in the Allowed Users field. Only those users will be able to trigger it — useful for preventing spam.

Counter & User Placeholders

Use special placeholders in your response text:

  • {count} — Replaced with the current counter value (if enabled).
  • {username} — Replaced with the name of the user who triggered the command.

Example: response Hello {username}, you are visitor #{count}!

Command Arguments

  • {1}, {2}, … — The 1st, 2nd, … word after the trigger phrase.
  • {args} — Everything after the trigger phrase.

Add a fallback after | for when the value is missing: {1|1} uses 1 if nobody typed a word after the command. Without a fallback, a missing value means the bot doesn't reply (the Activity Log says why).

Variables

Create variables in the Variables panel below a channel's triggers, then use them in any response:

  • {var:streak} — Current value.
  • {var:streak+1} / {var:streak-1} — Add / subtract, then show the new value.
  • {var:streak=0} — Set the value (numbers or text), then show it.
  • {var:streak+{1|1}} — Placeholders can be nested: adds the number typed after the command, or 1.

Example: !addstreak → Streak is now {var:streak+1}! and !currentstreak → Current streak: {var:streak}

Fetching Data

Give a trigger a Fetch URL and the bot loads it every time the trigger fires. Placeholders work in the URL too, e.g. https://example.com/last?id={1|1}.

  • {fetch:location.streetView} — A field from a JSON response (use items.0.name for arrays).
  • {fetch} — The whole response, for plain-text APIs.
  • {fetch:location.streetView|{fetch:error}} — Fallbacks work here too.

Use the Test button to see every field you can use. The API must allow cross-origin requests (CORS), since the bot runs in your browser.

Storage

All channels, triggers, and counter values are saved in your browser's local storage. They persist across page refreshes and browser restarts.
